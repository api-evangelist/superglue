# superglue

> superglue is an agentic implementation platform. Its AI agents help implementation teams run more implementations, faster.

## What the agents do

superglue's agents run the full implementation project, with any system: reading the source system, mapping and cleaning the data, configuring the target, migrating after sign-off, and keeping systems in sync post go-live. A consultant reviews and approves each step. Once a mapping is approved, execution is deterministic and fully traced. No AI runs at execution time.

There is no supported-systems boundary. The agents read a system's own documentation and build a working connector for anything reachable over REST, GraphQL, SOAP, ODBC, a database driver or file transfer, including legacy and on-premise software that connector libraries do not cover. Source data can also arrive as Excel, CSV or XML exports.

## Who it is for

ERP and business software implementation teams: value-added resellers, systems integrators, accounting and advisory firms, consultancies, and in-house implementation teams. superglue is not a developer integration library and not an iPaaS.
